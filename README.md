# Grow Flow — одностраничный сайт

Кинематографичный editorial-лендинг маркетингового агентства: тёмный фон,
тёплый шампань-акцент, интро-диафрагма при загрузке. Чистый HTML/CSS/JS,
без фреймворков и сборки — открывается напрямую или с любого статического
хостинга.

## Структура

```
index.html      — разметка всех секций
css/style.css   — все стили (палитра в :root)
js/main.js      — интерактивность
assets/         — логотип, фавиконка, видео
```

## Подключение видео

В начале `js/main.js`:

```js
const HERO_VIDEO_URL = "assets/hero.mp4"; // фоновое видео hero-секции
```

Сейчас подключён файл `assets/hero.mp4`. Чтобы заменить — положите свой
файл в `assets/` и обновите путь. Если строка пустая или файл не грузится,
секция автоматически возвращается к фолбэк-градиенту (`hero-gradient` +
`hero-noise`).

## Логотип

`assets/logo-mark.png` — монограмма бренда (прозрачный фон), используется
в шапке рядом со словесным знаком «Grow Flow». `assets/favicon.png` —
фавиконка на тёмной плашке. Оригиналы локапа — в `assets/brand/`.

## Плейсхолдеры

Весь контент (услуги, кейсы, команда, отзыв, статистика) — плейсхолдеры,
подлежащие замене на реальные тексты и изображения.

## Секции

Hero (100vh, видео, интро-диафрагма) · 01 Услуги (sticky-заголовок) ·
02 Кейсы (горизонтальный pinned-скролл) · 03 О нас (счётчики) ·
04 Команда · 05 Отзыв · финальный CTA с canvas-частицами · футер.

Кастомный курсор отключается на touch-устройствах (`hover:hover` /
`pointer:fine`); анимации уважают `prefers-reduced-motion`.
