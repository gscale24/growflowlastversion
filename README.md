# Grow Flow — одностраничный сайт

Кинематографичный монохромный лендинг маркетингового агентства.
Чистый HTML/CSS/JS, без фреймворков и сборки — открывается напрямую или с любого статического хостинга.

## Структура

```
index.html      — разметка всех секций
css/style.css   — все стили (палитра в :root)
js/main.js      — интерактивность
```

## Подключение видео

В начале `js/main.js` две константы:

```js
const HERO_VIDEO_URL = "";      // фоновое видео hero-секции
const SHOWREEL_VIDEO_URL = "";  // видео секции «Шоурил»
```

Подставьте URL своих файлов (mp4/webm). Пока строки пустые, показываются
монохромные фолбэк-фоны. Превью-видео кейсов подключаются через атрибут
`data-video=""` у плиток `.tile` в `index.html` (hover-to-play).

## Плейсхолдеры

Весь контент (услуги, кейсы, команда, отзывы, статистика, контакты) —
плейсхолдеры, помеченные в разметке. Фото команды и превью кейсов —
градиентные заглушки: замените на реальные изображения. Форма работает
в демо-режиме без бэкенда — точка подключения помечена в `initForm`
(js/main.js).

## Секции

Hero (100vh, видео) · бегущая строка клиентов · 01 Услуги · 02 Кейсы (bento)
· 03 Шоурил · 04 О нас (счётчики) · 05 Команда · 06 Отзывы · 07 Контакты · футер.

Кастомный курсор, магнитные ссылки и параллакс автоматически отключаются
на touch-устройствах; анимации уважают `prefers-reduced-motion`.
