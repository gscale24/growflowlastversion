# Grow Flow — scroll-driven одностраничник

Кинематографичный сайт-сцена: hero-видео с логотипом → три sticky-секции,
где скролл покадрово управляет видеорядом (canvas frame-scrubbing), как
объекты в детальных product-шотах. Чистый HTML/CSS/JS, без фреймворков.

## Структура

```
index.html       — вся разметка (hero + 3 сцены + модалка + футер)
css/style.css     — стили, палитра в :root
js/main.js        — вся логика: прелоадер, scrubbing-движок, сцены
assets/hero.mp4          — фоновое видео hero
assets/logo-mark.png     — логотип в hero
assets/frames/sceneA/    — 40 кадров: посадка в кресло
assets/frames/sceneB/    — 45 кадров: ручка + услуги
assets/frames/sceneC/    — 50 кадров: карточка с заметками + форма
```

## Как это работает

Каждая сцена — секция высотой `400vh` с `position: sticky` канвасом
внутри. Прогресс скролла по секции (0..1) мапится на индекс кадра
JPEG-последовательности и перерисовывается в канвас (`makeScrubber` в
`js/main.js`). Все 135 кадров прелоадятся при заходе на сайт — прогресс
показан на стартовом экране-прелоадере.

- **Hero** — фоновое видео (`HERO_VIDEO_URL` в начале `js/main.js`) с
  логотипом; при скролле плавно гаснет и увеличивается, открывая сцену A.
- **Сцена A** («знакомство») — кадр = положение скролла, текст и CTA
  «Листай дальше…» появляются на заданном участке прогресса.
- **Сцена B** («услуги») — те же кадры сегментированы на 4 части
  (по числу услуг), справа подсвечивается активная услуга. Клик или
  цифровая клавиша 1–4 открывает модалку с составом работ.
- **Сцена C** («контакты») — первые 34 кадра раскрываются по скроллу,
  дальше поверх статичного кадра — **концепт-мокап телефона**: живой
  текст, синхронный вводу в полях формы, с курсором и пульсацией на
  каждое нажатие. Это имитация до реальной съёмки руки с телефоном —
  помечена тегом «Концепт · заменить на съёмку» прямо в интерфейсе.
- **Индикатор прогресса** справа — вертикальная шкала с метками текущего
  раздела, ориентир в длинной scroll-driven странице.

## Плейсхолдер-материалы, которые нужно заменить

Кадры всех трёх сцен — референсная съёмка для обкатки механики
(во всех кадрах видны чужие вшитые субтитры). Перед публикацией:

1. Переснять сцены A/B/C под свой сюжет и экспортировать как
   `f_001.jpg … f_0NN.jpg` (нумерация с ведущими нулями, 3 знака) —
   ширина/высота и число кадров подставляются в `SCENES_META` в
   `js/main.js`, менять код не нужно, только число во `frames`.
2. Сцена C: когда будет снята сцена с телефоном в руке — можно либо
   продолжать использовать phone-мокап (он не привязан к конкретному
   видео, только к прогрессу скролла и полям формы), либо убрать оверлей
   и синхронизировать печать с новыми кадрами по той же схеме, что в
   сцене B (сегменты).
3. Hero-видео — `assets/hero.mp4`.

## Адаптивность

На экранах уже 820px индикатор прогресса и phone-мокап скрываются,
панели услуг/контактов растягиваются на всю ширину поверх видео.
Анимации уважают `prefers-reduced-motion`.
