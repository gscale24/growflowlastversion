# Grow Flow — scroll-driven одностраничник

Кинематографичный сайт-сцена: hero-видео с логотипом → сцены, где скролл
покадрово управляет видеорядом (canvas frame-scrubbing), как объекты в
детальных product-шотах, → контакты → гигантская надпись с видео в маске
букв как финальный аккорд, а следом её статичное эхо в футере. Чистый
HTML/CSS/JS, без фреймворков.

## Структура

```
index.html       — вся разметка (hero + сцены + модалка + outro + футер)
css/style.css     — стили, палитра в :root
js/main.js        — вся логика: прелоадер, scrubbing-движок, сцены, outro
assets/hero.mp4          — фоновое видео hero и outro
assets/logo-mark.png     — логотип в hero
assets/frames/sceneA/    — 40 кадров: посадка в кресло
assets/frames/sceneB/    — 45 кадров: фон сцены услуг
assets/frames/sceneC/    — 50 кадров: карточка с заметками + форма
```

## Как это работает

Каждая scroll-scrubbing сцена — секция высотой `400vh` с
`position: sticky` канвасом внутри. Прогресс скролла по секции (0..1)
мапится на индекс кадра JPEG-последовательности и перерисовывается в
канвас (`makeScrubber` в `js/main.js`), с интерполяцией между соседними
кадрами по дробной части прогресса — сглаживает переходы при небольшом
числе кадров. Все 135 кадров прелоадятся при заходе на сайт — прогресс
показан на стартовом экране-прелоадере. Скролл сглажен через lerp
(`smoothY` в `js/main.js`), не завязанный на частоту кадров.

- **Hero** — фоновое видео (`HERO_VIDEO_URL`) с логотипом; при скролле
  плавно гаснет и увеличивается, открывая сцену A.
- **Сцена A** («знакомство») — кадр = положение скролла, текст и CTA
  «Листай дальше…» появляются на заданном участке прогресса.
- **Сцена B** («услуги») — вкладки слева (SMM / Таргет / SEO / Продакшн).
  Гигантское слово по центру переключается не рывком, а непрерывным
  scroll-parallax: уходящее и входящее слово едут навстречу друг другу
  строго по дробному прогрессу скролла внутри сегмента (без CSS-transition,
  чтобы не было запаздывания), плюс лёгкий параллакс-дрейф самого кадра
  видео в такт. Клик по вкладке скроллит к нужному участку сцены; клавиши
  1–4 и кнопка «Подробнее о составе работ» открывают модалку с полным
  списком.
- **Сцена C** («контакты») — первые 34 кадра раскрываются по скроллу,
  дальше поверх статичного кадра — **концепт-мокап телефона**: живой
  текст, синхронный вводу в полях формы, с курсором и пульсацией на
  каждое нажатие. Помечена тегом «Концепт · заменить на съёмку».
- **Outro** («финал») — во весь экран надпись «GROW FLOW», внутри букв
  которой играет видео (canvas + `globalCompositeOperation:
  'destination-in'`). Рисуется только пока секция видна во вьюпорте.
  Если видео не загрузится — плейн-текстовый фолбэк.
- **Футер** — статичное эхо той же надписи «GROW FLOW» крупным кеглем
  над копирайтом: спокойный типографский финал после анимированного outro.
- **Индикатор прогресса** справа — вертикальная шкала с метками текущего
  раздела по всем секциям.

## Плейсхолдер-материалы, которые нужно заменить

Кадры сцен A/B/C — референсная съёмка для обкатки механики (во всех
кадрах видны чужие вшитые субтитры). Перед публикацией:

1. Переснять сцены A/B/C под свой сюжет и экспортировать как
   `f_001.jpg … f_0NN.jpg` (нумерация с ведущими нулями, 3 знака) —
   ширина/высота и число кадров подставляются в `SCENES_META` в
   `js/main.js`, менять код не нужно, только число во `frames`.
2. Сцена C: когда будет снята сцена с телефоном в руке — можно либо
   продолжать использовать phone-мокап (он не привязан к конкретному
   видео, только к прогрессу скролла и полям формы), либо убрать оверлей
   и синхронизировать печать с новыми кадрами по той же схеме, что в
   сцене B (сегменты).
3. Hero и outro-видео — `assets/hero.mp4` (`HERO_VIDEO_URL` и
   `OUTRO_VIDEO_URL` в `js/main.js`, можно указать разные файлы).

## Адаптивность

На экранах уже 820px индикатор прогресса и phone-мокап скрываются,
панель контактов растягивается на всю ширину поверх видео. Анимации
уважают `prefers-reduced-motion`.
